La Plant Store API proporciona una plataforma completa para crear aplicaciones de venta minorista de plantas. Desde la gestión del catálogo y el seguimiento del inventario hasta el procesamiento de pedidos y la gestión de las relaciones con los clientes, nuestra API se encarga de la complejidad para que puedas centrarte en crear experiencias sobresalientes.

<div id="core-capabilities">
  ## Capacidades principales
</div>

Crea operaciones completas de venta de plantas con estas capacidades integradas:

| Capacidad | Qué puedes hacer |
|------------|-----------------|
| **Gestión de Plant** | Organiza tu catálogo con categorías, etiquetas y metadatos enriquecidos |
| **Procesamiento de pedidos** | Gestiona el ciclo completo desde el carrito hasta la entrega |
| **Gestión de clientes** | Crea relaciones con perfiles, preferencias e historial |
| **Seguimiento de inventario** | Mantén existencias precisas con actualizaciones y alertas en tiempo real |

<Tip>
¿Nuevo en la Plant Store API? Comienza con la [Descripción general](/overview) para comprender la plataforma y luego sigue la [Guía de inicio rápido](/quickstart) para realizar tu primera llamada a la API.
</Tip>

<div id="what-you-can-build">
  ## Qué puedes crear
</div>

- **Sitios web de comercio electrónico** - Tiendas en línea con inventario en tiempo real y proceso de pago
- **Aplicaciones móviles** - Experiencias de compra nativas en iOS y Android
- **Sistemas de inventario** - Seguimiento y gestión de existencias en múltiples ubicaciones
- **Paneles de administración** - Herramientas internas para gestionar el catálogo y los pedidos
